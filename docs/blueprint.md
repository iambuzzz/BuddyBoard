# **App Name**: BuddyBoard

## Core Features:

- Task Input: Allow users Riya and Ambuj to add tasks to their respective lists through a form.
- Task Display: Display tasks for each user in a scrollable list.
- Task Completion: Allow users to mark tasks as complete, indicated visually with a strike-through effect and change of background color.
- User Theme Persistence: Use browser storage to remember which user's view was last displayed (Riya or Ambuj) and maintain theme-consistent styling upon revisit.
- Task Prioritization Tool: AI tool suggests the next most important task based on entered tasks, estimating effort, importance, and deadline, and providing recommendations on which tasks to focus on.
- Task Locking: Ability to 'lock in' the task list, preventing further edits. Adds visual styling to reinforce its locked state.
- Score Tracking: Keep track of completed vs. total tasks. Shows a total (lifetime) score and today's score.

## Style Guidelines:

- Primary color: Light periwinkle (#E0BBE4), offering a soft, calm, and modern feel to the interface.
- Background color: Very light periwinkle (#F8F8FF), providing a clean and unobtrusive backdrop.
- Accent color: Soft lavender (#9FA8DA), for highlighting interactive elements.
- Font: 'Poppins', a geometric sans-serif for a precise and contemporary look.
- Use simple, outlined icons from a set like Heroicons or Feather for clarity and a modern feel.
- Employ a clean, card-based layout with ample spacing to improve readability and focus.
- Incorporate subtle transitions and animations for a smooth, engaging user experience.
